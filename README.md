## 1. ¿Para qué crees que se usan los operadores lógicos en programación?
Los operadores lógicos se usan para hacer comparaciones entre datos, para hacer que dependiendo de la respuesta que obtengamos nuestro programa realice algo o no, como lo podría ser recibir la contraseña y usuario correctos para iniciar sesión

## 2. ¿Por qué es importante declarar correctamente el tipo de dato de una variable?
Especialmente en lenguajes como c# es requerido directamente por el mismo lenguaje, porque sino marcará un error. Se debe declarar el tipo de dato que esperamos usar, por ejemplo si la variable va a recibir un nombre usamos tipo string y si esperamos un número usamos int
